# NekuLoader 3.2.0-alpha.4 — Windows and Linux UI update

Free proprietary alpha. Download at https://nekudev.com/nekuloader/ .
Original code/asset rights remain reserved; third-party notices are included.

## Interface changes

- The player is attached to the bottom edge and remains on the Player page.
- Neku rests above the player. Click to pet, drag to reposition, or use the
  left/right arrow keys while focused. Placement is remembered locally.
- Planets drift independently and respect reduced-motion settings.
- The idle Direct download / Metadata matching boxes have been removed.

The frontend assets match the Nov 11 notarized Mac UI update. macOS remains
on its existing signed/notarized alpha.3 revision; this release updates the
Windows and Linux installers. No new Mac installer is required for these changes.

## Downloads and limits

- Windows 10/11 x64: `NekuLoader_3.2.0-alpha.4_x64-setup.exe`.
  Unsigned testing installer. Native Windows installation, WebView2 and GUI
  feedback are still pending. Do not disable security software to run it.
- Debian 12 x64: `NekuLoader_3.2.0-alpha.4_amd64.deb`.
  Experimental GTK 3 / WebKitGTK 4.1 package. Native desktop and physical-phone
  tests remain open. Use your package manager to install the local DEB, e.g.
  `sudo apt install ./NekuLoader_3.2.0-alpha.4_amd64.deb`.
- Current Mac Apple silicon build:
  https://nekudev.com/nekuloader/downloads/NekuLoader_3.2.0-alpha.3_aarch64-notarized-20261111.dmg

The newer Linux package version is greater than alpha.3, allowing a normal
package upgrade. Existing data is not intentionally reset by this UI update.
No automatic application updater is included.

## Validation

- 29 frontend tests passed on the build hosts, including persistent-player,
  cat interaction and planet reduced-motion coverage.
- Windows: 49 Rust tests passed under Wine 11.10 Staging, 7 optional tests
  ignored. The x64 application and NSIS package/resource inventory were checked.
  This does not establish native Windows GUI or WebView2 compatibility.
- Debian 12 x64: 52 Rust tests passed, 7 optional tests ignored. Package upgrade
  from alpha.3 to alpha.4 succeeded, all linked libraries resolved, and the
  installed app remained running through a 25-second Xvfb process check.
  The WebKit sandbox override was used only inside the isolated root-owned
  test container; it is not embedded in the app and should not be used for a
  normal desktop installation.
- SHA-256 hashes of the production JavaScript/CSS assets match exactly across
  these packages and the already-tested Nov 11 Mac interface.
