# NekuLoader 3.2.0-alpha.3

A free proprietary desktop alpha. Download the current tested installer at
https://nekudev.com/nekuloader/ . Code and original asset rights are reserved;
third-party licenses are preserved separately.

## Available build

- macOS Apple silicon (arm64), macOS 12 or later: DMG installer.
- Unsigned and not notarized. This build has no Developer ID trust and macOS may
  block opening a downloaded copy. Only install if you accept this alpha's
  security and compatibility limitations. No automatic application updater.
- Experimental Debian 12 x64 `.deb`: built and installed in an isolated container,
  with frontend/Rust tests, linked-library checks, and headless startup verified.
  Requires GTK 3 and WebKitGTK 4.1. Interactive desktop and physical-phone tests
  remain open. This is not a general Linux compatibility claim.
- Windows and Intel Mac downloads are not currently offered.
  GitHub Actions jobs cannot start because the account has a billing lock.
  Linux was built independently in a resource-limited container.

## Changes

- Missing downloader components open the Components tab directly.
- Settings and queue dialogs contain keyboard focus and restore it on close.
- Clearing the playback queue or removing its final track stops and unloads audio.
- Pause and seek checkpoint playback position for reopening the app.
- Current library, album, and queue rows pause/resume without restarting playback.
- Album play/pause glyphs and accessible labels match the action.
- The website now follows the real Cosmic/pixel design and uses an actual app
  screenshot, with downloads gated by an explicit availability manifest.
- License and dependency notices, including MPL-covered dependency sources, are
  included in the app's Resources and distributed alongside the installer.

## Verification and limits

Passed on the existing macOS arm64 host: TypeScript, 24 frontend component tests,
52 Rust tests, production build, DMG integrity check and packaged-app launch.
Additional opt-in tests passed for live catalog metadata, local Wi-Fi sharing of
generated files, isolated component installation/health checks, and generated
media conversion. The component installation test reused host FFmpeg/FFprobe.

Native app testing completed an authorized Blender Foundation Big Buck Bunny
YouTube download, MP3/artwork verification, automatic library scan, playback,
seek/pause, quit/reopen position restoration, and final packaged album-row
pause/resume. Test-media attribution: (c) 2008 Blender Foundation /
www.bigbuckbunny.org, CC BY 3.0; https://peach.blender.org/about/ .

This is not a clean-machine install, notarization test, or human usability study.
Physical Android USB, iPhone/phone Wi-Fi transfer, Windows, Intel Mac and native
Linux desktop installation still need target-specific testing. An alpha is not
claimed to be stable because automated tests pass.

## Provider limits

YouTube/YouTube Music and SoundCloud use direct extraction for accessible media.
Spotify uses metadata matching, with track/album public-catalog fallback; matched
audio and quality may differ and full playlist fallback is unavailable. SpotDL
cannot output ALAC. Deezer tracks/albums/playlists and Apple songs/albums use
catalog matching with duration checks. Apple playlists are unavailable.
FLAC/WAV conversion cannot restore detail absent from the source.

Use media you own or are authorized to download. Required components are installed
only after choosing Settings → Components → Install required components.

## Linux validation details

Built using Rust 1.95.0 and Node 24.22.2 in Debian 12 x64, capped at two CPUs,
3 GB RAM and 512 PIDs. Passed 24 frontend tests and 52 Rust tests (7 opt-in tests
ignored), optimized `.deb` build, package installation and dependency resolution.
No missing libraries were reported by `ldd`; highest direct GLIBC symbol version
was 2.34, while the tested distribution baseline remains Debian 12 (glibc 2.36).

Both direct and installed executable process smoke checks stayed alive for the
25-second Xvfb test window (timeout exit 124). WebKit's sandbox was disabled only
inside the root-owned test container to permit this headless check; the app does
not contain that environment override and users should not apply it to normal
desktop installations. This does not verify a normal-user desktop sandbox or UI.

A separate temporary-data component-install test installed and health-checked
managed yt-dlp, Deno, FFmpeg and FFprobe without a host FFmpeg executable. Optional
SpotDL was unavailable; supported catalog fallback remains available. See package
metadata for system dependencies. Install the downloaded DEB using your package
manager, for example `sudo apt install ./NekuLoader_3.2.0-alpha.3_amd64.deb`.
