# Windows alpha test

Use a Windows 10/11 x64 computer. This is an unsigned testing build. Report any
Windows security warning accurately; do not disable antivirus or other security
protections to run it. If Windows blocks it and you choose not to proceed,
report that result too.

1. Download the EXE from https://nekudev.com/nekuloader/ and install it.
2. Confirm the app opens, then install required components from Settings.
3. Choose a test output folder and download media you own or may download.
   One licensed sample is Blender's Big Buck Bunny:
   https://www.youtube.com/watch?v=aqz-KE-bpKQ
   Attribution: (c) 2008 Blender Foundation / www.bigbuckbunny.org, CC BY 3.0;
   license details: https://peach.blender.org/about/ .
4. Check that the download completes, appears in Library and plays.
5. Pause, seek, close and reopen; check that state persists.
6. Try cancelling a queued item. Check that other queued work still proceeds.
7. If available, test Android transfer with your own spare test file.
8. Uninstall; report whether shortcuts and the app were removed correctly.

Send the app version, Windows version, CPU architecture, which step failed,
and the exact message or screenshot. Remove cookies, account details and
private source links from shared logs. Passing one person's test does not
establish compatibility with every Windows computer.
