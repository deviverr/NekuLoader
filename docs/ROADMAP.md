### P1 — качество и надёжность

- Прогресс плейлиста: yt-dlp печатает процент каждого трека, поэтому полоса «прыгает» 0→100 на каждой песне. Нужен общий прогресс «трек N из M».
- Spotify через SpotDL зависит от общих ключей Spotify API, которые регулярно получают rate limit. Нужен запасной путь: метаданные Spotify (oEmbed / embed-страница) → поиск на YouTube Music, как для Deezer/Apple.
- `cookies-from-browser chrome` на Windows не работает из-за App-Bound Encryption Chrome 127+. В UI надо рекомендовать Firefox или cookies.txt.
- Ошибки yt-dlp не переводятся в понятный текст (бот-проверка YouTube, 403/429, гео-блок, приватное видео). В боте (`nekubot/downloader.py::_friendly_failure`) уже есть такая логика — портировать.
- Нет повторной попытки упавших треков внутри плейлиста (yt-dlp пропускает их молча при `--ignore-errors`, а без него рвёт весь плейлист).
- Компоненты: Deno помечен обязательным, но загрузки yt-dlp работают и без него (хуже для YouTube). Стоит оставить обязательным только yt-dlp + FFmpeg.

### P2 — релиз Mac / Windows

- Подпись и нотаризация macOS (Developer ID + `notarytool`), иначе Gatekeeper блокирует запуск у обычных пользователей.
- Подпись Windows (Authenticode или Azure Trusted Signing), иначе SmartScreen.
- Автообновление приложения (`tauri-plugin-updater`) после выбора политики подписи.
- Смоук-тест на чистых Windows 11 x64 и macOS Intel/arm64 по чек-листу `docs/RELEASING.md`.
- Лицензия проекта и `THIRD_PARTY_NOTICES` (FFmpeg-сборки GPL/LGPL — проверить, что распространяется).

## 3. Передача музыки на телефон

Требование: iOS и Android, «чтобы просто работало».

1. **Wi‑Fi передача (iOS + Android, без кабеля и без приложений)** — основной путь. Приложение поднимает временный HTTP-сервер в локальной сети с одноразовым токеном и показывает QR-код. Телефон сканирует QR, открывается страница со списком треков: можно скачать по одному или всё одним ZIP. На iPhone файлы попадают в «Файлы», откуда их проигрывают VLC / Documents / любое приложение; на Android — в «Загрузки», музыкальные плееры их видят. Сервер выключается кнопкой или автоматически через 30 минут.
2. **Android по USB (ADB)** — для больших библиотек: выбор устройства, папка назначения, прогресс, пересканирование медиатеки.
3. **iPhone в приложение «Музыка»** — Apple не даёт стороннего API. Только Finder (macOS) / Apple Devices (Windows). Оставляем инструкцию.
4. Позже: мобильный клиент (Tauri 2 mobile или PWA), который сам забирает новые загрузки с компьютера.
